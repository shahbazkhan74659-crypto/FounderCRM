# FounderCRM

Internal role-based tool for a startup to log customer-discovery interviews with founders, track competitor intelligence (including pricing history), and surface auto-generated insights (budget ranges, feature requests) — gated behind an Admin/Staff permission model.

**Status:** Phase 0 (Planning). No stack chosen, no application code yet.

See `Project Docs/` for the full documentation system (project definition, roadmap, architecture, decisions, working rules).
